# LunarLightMC

月光服务器官网。仿 MDC 木纹像素风格，顶部按钮进入独立板块页面。

## 页面

- `index.html` 主页
- `network.html` 网络连接
- `play.html` 玩法与指令
- `hardware.html` 服务器配置
- `rules.html` 群规则
- `links.html` 相关链接
